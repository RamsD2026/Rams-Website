# Client logos — WebP handover

The twelve client marks shown in the logo grid on the `/clients` page hero,
exported as **lossless WebP** with transparent backgrounds.

They are prepared for a **dark background**: some marks have been adjusted
for it (Mahindra's "LOGISTICS" and IPCA's "ipca" set in white, Nestlé in
its grey single-colour form). On a white background, use the companies'
standard artwork instead.
